# TeamDocs: начать здесь

Это документационный сайт TeamDocs. Он хранится в репозитории рядом с приложением, но является **отдельным Node-проектом**: у него собственные `package.json`, `package-lock.json` и `node_modules`. Запуск и сборка сайта не требуют `npm install` в корне основного монорепозитория.

## Что здесь находится

- **Проект** — назначение TeamDocs, архитектура и структура репозитория.
- **Инженерия** — запуск, Docker Compose, контракты Zod и тестирование.
- **Учебный путь** — карта четырёх академий и практических недель из Roadmap.
- **Решения** — ADR: короткие записи о важных технических выборах.
- **Личный журнал** — опубликованные выводы после изучения и реализации.

## Быстрый запуск сайта

```bash
cd documentation
npm install
npm start
```

Сайт откроется на `http://localhost:3002/teamdocs/`.

## Принцип источника правды

Вся долговременная проектная информация должна появляться здесь: решение — в ADR, инструкция — в инженерном разделе, изученный материал — в журнале. README в корне остаётся короткой точкой входа для запуска приложения и ссылается на этот сайт.
