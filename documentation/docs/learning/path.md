# Учебный путь

Документация повторяет порядок Roadmap: сначала фундамент, затем backend, Python-сервисы и RAG. Каждая изученная тема должна получить практический след в TeamDocs и короткую запись в личном журнале.

## Порядок академий

1. **TypeScript Academy** — production TypeScript для frontend и backend.
2. **Backend & Databases Academy** — HTTP, NestJS, PostgreSQL, auth, testing и deployment.
3. **Python & AI Services Academy** — Python, FastAPI, data tooling и contracts.
4. **Applied ML & RAG Academy** — embeddings, retrieval, RAG, evaluation, security и budgets.

После академий применяется 12-недельный delivery plan. Не нужно переносить полный текст уроков из Notion автоматически: на сайте сохраняй реализованные решения, личные выводы и проектные инструкции, которые нужны рядом с кодом.
