# 00 · TypeScript Academy

Цель: уверенно проектировать и поддерживать TypeScript-код в production frontend и backend.

## Что фиксируем в проекте

- strict compiler options и отдельные конфиги для browser, Node/Vite config и NestJS;
- distinction between compile-time types and runtime validation;
- ESM imports в NestJS с `.js` specifiers;
- shared contracts через Zod и `z.infer`.

После каждого крупного блока добавляй в журнал: что построено, что оказалось сложным и какую ошибку не стоит повторять.
