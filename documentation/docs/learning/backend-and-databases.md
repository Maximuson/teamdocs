# 10 · Backend & Databases Academy

Цель: построить production API с NestJS, PostgreSQL, migrations, authentication, authorization и тестами.

## Следующий практический порядок

1. Добавить application-level database client и migrations.
2. Реализовать CRUD документов с validated request/response contracts.
3. Добавить JWT, refresh rotation и RBAC.
4. Покрыть domain logic unit tests и API/database границы integration tests.
5. Настроить staging, observability и delivery pipeline.

Контейнер PostgreSQL уже существует, но не считай database integration завершённой, пока в коде нет connection, migrations и проверенной операции записи/чтения.
