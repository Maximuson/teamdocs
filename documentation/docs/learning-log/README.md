# Личный журнал обучения

Здесь публикуются короткие, полезные будущему себе записи после изучения или реализации темы. Это не конспект всего курса и не копия Notion; это проверенный практикой вывод.

## Что должна содержать запись

- **Контекст:** какую задачу или тему изучали.
- **Главный вывод:** что теперь понятно.
- **Сложность:** где было легко ошибиться.
- **Пример из TeamDocs:** file, command или architectural decision.
- **Следующий шаг:** что проверить или изучить дальше.

## Workflow

1. Создай черновик в `documentation/notes/drafts/` по шаблону `documentation/templates/learning-note.md`.
2. Пиши свободно, без попытки сразу сделать текст идеальным.
3. После проверки выводов перенеси cleaned-up note в эту папку `docs/learning-log/`.
4. Добавь страницу в `sidebars.ts`, если это постоянная заметка, которую нужно находить через навигацию.

Черновики versioned вместе с кодом, но Docusaurus их не публикует. Так незавершённые мысли не попадают в основную навигацию.
