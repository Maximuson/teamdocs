# Architecture Decision Records

ADR — короткая неизменяемая запись о решении, которое влияет на архитектуру или workflow. Она отвечает на четыре вопроса: **контекст, решение, последствия, статус**.

- Новые записи создавай из `documentation/templates/adr.md`.
- Не переписывай историю, если решение уже применялось: добавь новую ADR, которая заменяет старую.
- Ссылки на ADR добавляй из связанной инженерной инструкции и pull request.
