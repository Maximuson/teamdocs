# Черновики заметок

Это личная рабочая папка. Файлы здесь хранятся в Git, но не публикуются Docusaurus.

Создай новый файл по `../../templates/learning-note.md`. Когда заметка перестанет быть черновиком и будет полезна для повторного чтения, перемести её в `../../docs/learning-log/` и добавь в sidebar.

Не храни здесь секреты, токены, персональные данные или неочищенные production logs.
